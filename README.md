# حضانة كوكب نور | Noor Planet Nursery

موقع ثنائي اللغة (العربية RTL افتراضياً + الإنجليزية LTR) لحضانة كوكب نور التابعة لمعهد أبناؤنا في الخارج – عجمان.

**التقنية:** HTML + CSS + JavaScript خالص، مع مولّد ثابت صغير (`build.js`) بدون أي اعتماديات — لا يوجد `npm install`.
المولّد يقرأ القوالب + ملفات الترجمة + ملفات البيانات ويُخرج موقعاً ثابتاً في `dist/` يعمل على أي استضافة.

---

## 1) التشغيل

المطلوب فقط: [Node.js](https://nodejs.org) إصدار 18 أو أحدث.

```bash
npm run dev      # يبني ويشغّل http://localhost:4173 ويعيد البناء تلقائياً عند أي تعديل
npm run build    # يبني الموقع النهائي داخل dist/
npm run assets   # (اختياري) يولّد نموذج التسجيل PDF وصورة المشاركة og-image.png عبر Chrome/Edge
```

## 2) النشر

| الاستضافة | الطريقة |
|---|---|
| **Vercel** | اربط المستودع؛ الإعدادات جاهزة في `vercel.json` |
| **Netlify** | اربط المستودع؛ الإعدادات جاهزة في `netlify.toml` |
| **استضافة عادية (cPanel)** | شغّل `npm run build` ثم ارفع **محتويات** مجلد `dist/` إلى `public_html` (ملف `.htaccess` مرفق) |

> الموقع مصمَّم ليعمل من **جذر النطاق** (مثل `https://example.com/`) وليس من مجلد فرعي.

**قبل النشر** غيّر `baseUrl` في `src/site.config.json` إلى النطاق الفعلي (يُستخدم في canonical و hreflang و sitemap و Open Graph).

## 4) كيف أعدّل…؟

بعد أي تعديل شغّل `npm run build` (أو اترك `npm run dev` يعمل).

### الأسعار — `src/data/pricing.json`
- `fees` : سعر كل برنامج لكل نظام دوام (`full` شهري، `half` شهري، `daily` لليوم، `hourly` للساعة).
- `extras.transport` : رسوم المواصلات الشهرية لكل منطقة — أضف/احذف مناطق بحرّية.
- `extras.meals / extended / uniform` : الوجبات، الدوام الممتد، اليونيفورم.
- `registrationFee` : رسوم التسجيل (ضع `0` لإخفائها).
- `discounts` : نسب خصم الإخوة والمعهد. `combine: true` يجمع الخصمين، `false` يطبّق الأعلى فقط.
- `installments` : عدد دفعات التقسيط المذكور في صفحة الرسوم.

جدول الرسوم، الحاسبة، معالج التسجيل، ورسالة واتساب تتحدّث كلها تلقائياً من هذا الملف.

### البرامج — `src/data/programs.json`
لكل برنامج: `name`, `age`, `minMonths`/`maxMonths` (يُبنى عليها الاقتراح التلقائي من تاريخ الميلاد)، `ratio`، `seats.total`/`seats.available` (مؤشر الأماكن المتاحة)، `goals`، `skills`، `image`.
عند إضافة برنامج جديد أضف له سطراً بنفس `id` داخل `pricing.json → fees`.

### القائمة الغذائية — `src/data/menu.json`
كل يوم: `day` (0 = الأحد … 6 = السبت) و `breakfast` / `snack` / `lunch` باللغتين.

### الجدول اليومي — `src/data/schedule.json`
كل محطة: `time` (24 ساعة)، `emoji`، `tone` (لون)، `title`، `desc`.

### الفعاليات والتقويم — `src/data/events.json`
- `events` : التاريخ بصيغة `YYYY-MM-DD`. العداد التنازلي يختار أقرب فعالية قادمة تلقائياً، والمنتهية تُعلَّم «انتهت».
- `news` : الأخبار. `calendar` : التقويم والإجازات في ركن الأهل.

### النصوص — `src/i18n/ar.json` و `en.json`
الملفان بنفس المفاتيح تماماً. المولّد يطبع تحذيراً إذا نقص مفتاح في أحدهما.
النصوص ثنائية اللغة داخل ملفات البيانات تُكتب هكذا: `{ "ar": "...", "en": "..." }`.

### بيانات التواصل وساعات العمل — `src/site.config.json`
`whatsapp`, `phones`, `email`, `address`, `mapQuery`, `geo`, `hours.days` (أرقام الأيام)، `visitSlots` (أوقات الزيارة)، `stats` (العدادات)، `social`، `announcement.show`.

### التحليلات
ضع المعرّفات في `site.config.json`:
```json
"analytics": { "gaId": "G-XXXXXXX", "metaPixelId": "1234567890" }
```
تُحقن الأكواد تلقائياً في كل الصفحات (وتبقى تعليقاً فارغاً إن تُركت فارغة).

### الألوان والخطوط
المتغيّرات في أول `src/assets/css/main.css` (`--sun`, `--sky`, `--violet` …). الألوان المتاحة لحقل `tone` في البيانات: `sun, sky, violet, pink, mint, orange`.

### الصور
- الصور الحالية **رسومات SVG مؤقتة تُولَّد تلقائياً** لأي مسار مذكور في البيانات وغير موجود في `src/assets/img/`.
- لاستبدال صورة: ضع الملف الحقيقي بصيغة **WebP** (مثل `src/assets/img/gallery/painting.webp`، عرض 1200px تقريباً، نسبة 4:3) وغيّر المسار في ملف البيانات. كل الصور تُحمَّل بـ `loading="lazy"`.
- **لا تُنشر أي صورة لطفل دون موافقة كتابية موقّعة من ولي الأمر.**

## 6) ملاحظات تقنية

- **النماذج بلا خادم:** معالج التسجيل، حجز الزيارة، التواصل، والتوظيف تبني رسالة وتفتح `https://wa.me/971555515049?text=…` (مرمّزة بـ `encodeURIComponent`). لا تُخزَّن أي بيانات على الموقع.
- **رقم الطلب:** `NP-[YYYYMMDD]-[3 أرقام]` يُولَّد في المتصفح ويظهر في الرسالة وصفحة الشكر.
- **SEO:** عنوان ووصف لكل صفحة باللغتين، canonical، hreflang (ar / en / x-default)، Open Graph، Schema.org (`ChildCare` + `LocalBusiness` في كل الصفحات، `FAQPage` في الأسئلة الشائعة)، `sitemap.xml`، `robots.txt`.
- **إمكانية الوصول:** رابط تخطٍّ للمحتوى، نصوص بديلة، تركيز واضح بلوحة المفاتيح، ألوان نصوص بتباين AA، واحترام `prefers-reduced-motion`.
- **الأداء:** لا مكتبات خارجية، CSS واحد، سكربتات `defer`، رسومات SVG مضمّنة، خطوط Google بـ `display=swap`.
- **اللغة:** الجذر `/` يحوّل إلى `/ar/` (أو إلى آخر لغة اختارها الزائر).
- **إضافة صفحة جديدة:** أضف دالة `render` في أحد ملفات `src/templates/pages/` وسجّلها في مصفوفة التصدير، ثم أضف `meta.<key>.title/desc` و `nav.<slug>` في ملفي الترجمة.
